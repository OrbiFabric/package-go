# Core identity and logical tree model (S02)

Frozen authority remains `7ff166365dc83cee783e4e6715225968c81ef7b9`, contracts 005/006/007/020. API types are provisional; no V1 identity encoding or migration exists.

PackageID, VersionID, FileID, FolderID and ContentID are distinct Go types. UUID validation accepts only lowercase RFC 9562 UUIDv7 with variant 8/9/a/b. IDGenerator uses secure randomness by default, writes the explicit epoch milliseconds/version/variant bits, prevents collisions against a seeded ever-used Package inventory, and bounds collision retries. Hosts seed all historical IDs, including removed entities, and serialize cross-process publication. UUID timestamp order is never parent/ordinal authority. Zero/uninitialized generators fail without panicking.

ParseTimestamp accepts exact UTC microsecond strings, real Gregorian dates in years 0001..9999, no offset/leap-second/variable precision. Timestamp renders explicit Host time in UTC at microsecond precision. NewPackage creates only immutable identity/creation facts; product metadata and DB locators have no Package fields. ContentIDForBytes hashes raw whole-file bytes, including empty bytes, without path/newline/text conversion. ContentRequest and verified-copy boundaries now use the distinct ContentID type.

ReadPackage implements the closed Package schema. ReadVersion requires every field including explicit nullable parent, validates ordinal/date/protocol/capabilities/profiles and sealed metadata, and retains allowed optional facts. ReadManifest implements file/folder schema branches, rejects both identity fields, missing/invalid content size and folder file-fields, preserves optional fields, and validates the implicit Root/parent/name topology. Entries sort by a single UUID-text order across files/folders; empty folders are explicit; nil parent is a Root child. Missing/non-folder parents, cycles, duplicate IDs/sibling names and unequal sizes for the same ContentID are rejected. IdentityInventory preserves historical kind continuity across validated manifests.

Public structs represent provisional model values. Callers validate constructed data before use; serialization alone is not history/commit validation. JSON marshaling preserves allowed optional values and rejects extras shadowing known/forbidden branch fields, including absent optional fields. It does not produce protocol canonical bytes. All publication and complete-history checks remain downstream work.

NewFileEntry/NewFolderEntry create new IDs. WithPlacement preserves file/folder identity; WithContent preserves FileID and replaces content facts; CopyFile assigns a new FileID and can reuse ContentID. These operations make independently cloned working proposals, including nested optional JSON; source committed models stay unchanged. Proposals retain their source VersionID as a reference and must receive a new VersionID through the future commit operation; they are never written into committed history by these helpers. Generator reservations consumed by rejected proposals may remain reserved, preventing accidental reuse.

Entry names validate the schema and exact Unicode 16.0.0 NFC. Unicode tables are generated from pinned [Unicode 16 UCD](https://www.unicode.org/Public/16.0.0/ucd/) inputs; source hashes, generator, data license and compressed official NormalizationTest are retained. The runtime implements canonical decomposition/order/composition, including algorithmic Hangul, without compatibility mapping or stream-safe CGJ insertion. It uses neither host Unicode tables nor a different Unicode edition. All 19,965 official NFC rows pass. Regeneration requires the exact local source files and verifies pinned hashes; runtime/tests perform no network access.
